字幕摘录 1.1 · Windows 11 实时字幕复制工具

使用方法
1. 双击 CaptionCopy.exe。无需安装、联网或管理员权限。
2. 打开 Windows 自带的实时字幕（Win + Ctrl + L）。也可以点击工具里的“打开实时字幕”。
3. 播放视频、课程等声音。字幕会自动分成便于复制的小段，累积到工具中。
4. 点击一段即可复制；“复制全部”复制本次累计的全部字幕，每段一行。
5. “清空”删除本次内容，后续只显示新增字幕。“置顶”让窗口保持在其他窗口上方。

补充说明
- 较浅色的末句仍在更新，也可以直接点击复制。
- 自动分段不需要等待说话者停顿：句末标点优先，较长内容遇到逗号等也会切分。
- 连续讲话且完全没有标点时，也会自动按长度切分，中文通常约 20–50 字一段，英文尽量保持单词和数字完整。
- 已有足够内容时，约 0.7 秒文字无变化也可辅助分段；极短片段会多等待一会儿，避免切得太碎。
- 向上滚动查看旧句时不会自动跳到底部。点击“回到最新”恢复跟随。
- Ctrl + Shift + C 可以复制全部（仅工具窗口内有效）。
- 所有记录只在内存中，退出即清空，不保存音频、字幕或历史文件。
- 关闭工具不会关闭系统实时字幕。

系统要求与限制
- Windows 11，且系统自带实时字幕可正常使用；首次使用请先完成系统语言包设置。
- 使用 Windows 内置 .NET Framework 4.8，无需另装 Python 或 .NET 桌面运行时。
- 识别语言在系统实时字幕的设置中选择，工具不改变系统语言设置。
- 原文由 Windows 识别；工具不额外纠错或润色。分段依靠标点、长度和文字更新间隔，不是语法或音频分析。
- 必须保持系统实时字幕开启。工具只保留运行期间实际读取到的字幕，不能找回启动前已滚走的内容。
- 系统更新可能改变字幕控件；若提示不兼容，请确认系统字幕已经完成设置并能显示文字。

源码与构建
- src：程序源码；tests：文本处理、剪贴板及真实字幕读取测试。
- assets：软件图标及矢量源文件；tools\New-AppIcon.ps1 可重新生成 16–256 像素的多尺寸 ICO。
- build.ps1：使用 .NET Framework 4.8 Developer Pack 和 Windows 自带编译器构建。
- PowerShell 中运行：.\build.ps1 -Test
- artifacts\CaptionCopy.exe 为便携程序，可单独复制到其他目录使用。
- 也可用具备 .NET Framework 4.8 开发支持的 Visual Studio 打开 CaptionCopy.csproj。
