# 字幕摘录 1.2

<img src="assets/AppIcon.png" width="72" alt="字幕摘录图标" />

**把 Windows 11 实时字幕变成可以随手复制的文字。**

## 下载与使用

从 [发布页面](https://github.com/zaunpowpow/win11-caption-copy/releases/latest) 下载便携版压缩包，解压后双击 `CaptionCopy.exe`，点击“打开实时字幕”并播放声音即可。

- 点击一段复制；按住左键拖过多段，松开后按原文顺序一次复制；“复制全部”复制本次累计的所有内容，每段一行。
- “设置”可调节窗口不透明度（30%–100%），支持文字清晰度保护和恢复默认。
- 连续讲话也会自动分段，中文通常约 20–50 字一段，不必等说话者停够两秒。
- 支持清空、置顶、查看旧字幕和恢复跟随。
- 全程本地运行，无需账号、API 密钥或额外识别模型，退出后不保存字幕记录；仅将透明度偏好保存在本机。

需要 Windows 11 自带实时字幕可以正常使用，首次使用请先完成系统语言包设置。本项目是独立的辅助工具，与微软无隶属关系。

Windows 11 实时字幕的本地复制助手。连续讲话也会自动分成小段，点击一段复制，或一键复制本次累计的全部内容。

便携成品位于 `dist/CaptionCopy.exe`，中文说明位于 `使用说明.txt`。无需安装，无需管理员权限，不联网，不写入字幕、音频或历史记录。

## 多选与透明度

按住鼠标左键拖过字幕段落，选区会高亮，松开后自动复制。不需要按 Ctrl，向上拖选也会按从上到下的顺序复制。拖到列表上下边缘可以继续滚动选取；Esc、切换窗口或丢失鼠标捕获会取消此次拖选。拖选期间暂停字幕刷新，避免识别更新改变选区；结束后继续接收字幕，点击“回到最新”恢复自动跟随。

开启“保护文字清晰度”时，文字和图标保持不透明，界面背景随滑块淡化；关闭时，整个主窗口一起变淡。设置窗口始终保持清晰。为支持真正的透明背景，主窗口使用自绘标题栏，保留拖动、最小化、最大化/还原、关闭和右下角缩放。

设置保存在 `%LOCALAPPDATA%/CaptionCopy/settings.xml`，仅包含不透明度和文字保护开关，不含字幕。默认 100% 不透明，开启文字保护；损坏或不可读的设置回退到默认值，保存失败不会阻止使用。

## 构建与测试

需要 Windows 和 .NET Framework 4.8 Developer Pack。无需 NuGet 包。

```powershell
.\build.ps1 -Test
```

输出为 `artifacts/CaptionCopy.exe`。可用 `-OutputDirectory` 指定其他输出目录。也可在支持 .NET Framework 桌面开发的 Visual Studio 中打开 `CaptionCopy.csproj`，或运行：

```powershell
dotnet build .\CaptionCopy.csproj --configuration Release
```

自动测试包括连续快照合并、中英文分句、连续无停顿/无标点讲话、短停顿、英文单词和数字完整性、Unicode 边界、滚动重叠、识别修订、重复发言、清空基线、延迟标点、长序列、多尺寸图标，以及真实剪贴板临时/持续占用。剪贴板测试使用独立子进程持有剪贴板，并在测试结束后释放。

额外的本机集成检查（需先启动工具和 Windows 实时字幕）：

```powershell
# 运行 15 分钟，记录连接状态、样本字数和工具响应/内存；不记录字幕正文。
.\artifacts\CaptionCopy.Tests.exe --live 900 .\artifacts\live-smoke.csv

# 在“复制全部”后，核对剪贴板是否为当前系统字幕原文的完整后缀。

```

## 内部结构

- `CaptionReader`：独立 MTA 后台线程，每约 300ms 读取 `LiveCaptions` 的 `CaptionsTextBlock`。断开后每秒寻找窗口，控件失效时重新定位。只向界面发送文本快照和连接状态，不操作系统字幕的窗口布局、麦克风或语言设置。
- `TranscriptEngine`：将当前系统快照映射到累计文本的末尾区域，保留已滚走的历史，允许最近区域修订。清空时只保留隐藏的当前快照基线，避免旧字幕回流；重连时开始新片段。
- `SentenceSplitter`：句末标点优先，较长逗号分句按小段切开；完全无标点时按长度切分，不依赖停顿。用中文字符 2 单位、普通英文字符 1 单位计宽，分句最小 36 单位、目标 72 单位、兜底 104 单位；英文单词和数字边界优先，单个超长单词/URL 可超过阈值以保持完整。
- 约 700ms 的文本停顿只在末段达到 24 单位时辅助分段；更短片段保留 2 秒兜底。短停顿不会缩短两秒的识别修订窗口。
- WPF 界面与 `ClipboardService`：虚拟化句子列表，增量更新句子，用户翻阅时暂停跟随；STA 线程操作 Unicode 剪贴板，短暂重试并反馈结果。主界面 XAML 直接嵌入 EXE，便携运行不依赖旁边的资源文件。
- `assets/App.ico`：16–256 像素多尺寸字幕气泡/复制卡片图标，同时嵌入 Windows EXE 与 WPF 窗口。`AppIcon.svg` 为矢量设计，`tools/New-AppIcon.ps1` 仅用 Windows/.NET 绘制并重建 ICO，无需图像库或联网。

## 行为边界

识别质量、语言支持和标点来自 Windows。工具不会润色原文。自动分段依靠标点、长度和文字更新间隔，并不分析音频或判断语法意义上的完整句子；连续讲话没有停顿也会分段。复制全部时保留原文字符与标点，每段之间插入换行。

工具只保存实际读取到的快照，无法找回启动前已经滚走或两次采样之间消失的字幕。完全相同且没有任何可观察变化的两个快照，无法判断是重复采样还是另一次完全相同的发言；窗口内正常增长的重复句子会保留，不做全局文本去重。

系统字幕控件不是专门的字幕导出协议；Windows 更新可能改变它。无法找到控件时工具给出明确状态，第一版不包含 OCR 替代路径。
